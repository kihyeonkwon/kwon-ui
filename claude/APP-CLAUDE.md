# 앱의 CLAUDE.md에 넣는 문구

kwon-ui를 넣은 앱의 CLAUDE.md에 아래를 그대로 넣습니다. 짧게 둡니다. 지켜지게 하는 것은 이 문구가 아니라 검사(`kwon-ui check`)와 훅입니다.

```
디자인 시스템: kwon-ui

'디자인 시스템', '공통 컴포넌트'는 모두 kwon-ui(패키지 kwon-ui)를 뜻한다. 이 앱의 화면은 kwon-ui로만 만든다.

- 화면 작업 전에 node_modules/kwon-ui/CATALOG.md 를 읽고, 거기 있는 조각으로 짠다.
- 색, 글자 크기, 굵기, 모서리 값을 앱 코드에 직접 쓰지 않는다. kwon-ui 의 토큰(var(--n-…))과 조각만 쓴다. 앱 고유의 색은 kwon-ui.config.json 의 tokenFiles 에 적힌 파일에서만 변수로 정의한다.
- n- 으로 시작하는 이름과 --n- 토큰을 앱에서 만들거나 다시 정의하지 않는다. 앱의 조각은 앱 접두어로 짓는다.
- 필요한 조각이 없으면 페이지에서 비슷한 것을 새로 만들지 않는다. 멈추고 "kwon-ui 에 추가할 것"을 제안한다. 한 페이지에서만 쓸 조각이면 앱 접두어로 만들고 토큰만 쓴다.
- 끝내기 전에 npm run check:design 을 통과시킨다. 검사를 끄거나, 기준선을 올리거나, 예외로 넘기지 않는다.
```
